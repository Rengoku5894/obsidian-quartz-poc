# Troubleshooting

This section provides a consistent approach for investigating technical issues.

## Troubleshooting Process

1. Identify the problem and record the error message.
2. Gather logs and configuration information.
3. Reproduce the issue.
4. Test the suspected component.
5. Apply the validated resolution.
6. Validate that the issue is resolved.
7. Document the root cause and resolution.

> [!TIP]
> A resolved incident can become a new knowledge article when the resolution is likely to be useful again.

## Application Not Detected

See [[PowerShell#Installed Application Detection]].

## Incorrect Application Version

Check the application's `DisplayVersion` value and compare it with the required version.
