# Getting Started

The IT Knowledge Base provides technical documentation, operational procedures, troubleshooting guides, commands and reference information.

## Architecture

**Obsidian → GitHub → Quartz 5 → GitHub Pages**

## How Content Is Published

1. Create or modify a note in Obsidian.
2. Save the Markdown file.
3. Commit the changes using Git.
4. Push the changes to GitHub.
5. GitHub Actions runs the Quartz 5 build.
6. Quartz generates the static website.
7. GitHub Pages publishes the generated website.
