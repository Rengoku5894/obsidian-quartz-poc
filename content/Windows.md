## Check Windows Version

Press `Win + R` and run `winver`.

Alternatively, run `systeminfo`.

## Windows Registry

The Windows Registry can be useful when investigating installed applications, configuration settings and application versions.

> [!WARNING]
> Registry changes can affect operating system and application functionality. Validate changes before modifying registry values.
