# IT Knowledge Base

Welcome to the IT Knowledge Base.

This Proof of Concept demonstrates a Markdown-based knowledge management and publishing architecture using:

**Obsidian → GitHub → Quartz 5 → GitHub Pages**

## About This POC

1. Written and maintained in Obsidian.
2. Stored as Markdown files.
3. Version controlled using Git.
4. Stored in GitHub.
5. Converted into a website using Quartz 5.
6. Published using GitHub Pages.
